# Arcade with Agent Frameworks and MCP Clients

Arcade integrates with agent frameworks and  clients to add \-calling capabilities to your AI applications.

These guides are for developers building AI applications who need to connect Arcade tools to their agent frameworks or  clients. You’ll learn how to authenticate with Arcade, load , and execute them within your chosen framework. Each guide provides code examples and configuration steps to get you started quickly with the most popular frameworks and programming languages.
